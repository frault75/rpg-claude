# Palimpsest

A story-driven, turn-based RPG for desktop browsers, in HD-2D pixel art: a pixel world lit, fogged and blurred like the Octopath and 16-bit Final Fantasy games.

Built with Three.js, Vite and TypeScript. Every image, letter and sound is generated by code at runtime. The repository contains no asset files.

- **Design:** [DESIGN.md](DESIGN.md)
- **Play:** https://frault75.github.io/rpg-claude/ (deployed from `main` by GitHub Actions)

## Current state: the HD-2D engine

One map: the Sea Gate of Saint Ebb's by night. The camera comes down from the spire of the abbey church to the causeway, where Isot and Hild walk in from the sea and a knight in white stands in the shallows.

## Develop

```sh
npm install
npm run dev      # http://localhost:5173/rpg-claude/
npm test         # unit tests (Vitest)
npm run build    # typecheck and build into dist/
```

With the dev server running, `/rpg-claude/dev/preview.html?what=characters&scale=6` (or `what=faces`) shows the generated sprites enlarged.

## Layout

```
src/
  engine/   view geometry, input, RNG and noise, saves
    hd2d/   the HD-2D renderer: world pass (albedo + emissive), light buffer, composite
            with fog, particles, bloom, tilt-shift, grade; water and sky shaders
  pixel/    procedural pixel art: the PixelImage toolkit (ramps, dithering, outlines),
            characters, terrain, buildings, nature, props, sprites
  world/    actors, the walkable grid and A*, the stage that holds a scene's things
  audio/    Web Audio engine, synthesised instruments, generative chant, sound effects
  story/    flags, conditions and the script runner
  scenes/   screens of the game (for now, the Sea Gate)
  debug/    the debug overlay
tests/      unit tests
```

## Deployment

`.github/workflows/deploy.yml` builds and deploys to GitHub Pages on every push to `main`. One-time setup: in the repository's **Settings → Pages**, set **Source** to **GitHub Actions**.
