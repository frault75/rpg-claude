# Palimpsest

A story-driven, turn-based RPG for the browser (desktop and mobile), in HD-2D: pixel art standing in a lit 3D diorama, in the manner of Octopath Traveler.

Built with Three.js, Vite and TypeScript. Every image, letter and sound is generated by code at runtime. The repository contains no asset files.

- **Design:** [DESIGN.md](DESIGN.md)
- **Play:** https://frault75.github.io/rpg-claude/ (deployed from `main` by GitHub Actions)

## Current state: the diorama engine

One map: the Sea Gate of Saint Ebb's by night. The camera comes down the abbey's tower to the sea gate, where Isot and Hild set out along the causeway; a knight in white stands in the shallows, and meeting him plays a short cinematic.

The world is real 3D seen by a tilted orthographic camera: ground, cliffs, stairs, walls and roofs are planes textured with procedural pixel art, figures and trees stand as upright sprites. The moon casts soft shadows, lamps and torches light their surroundings, the sea reflects the scene, and depth of field, mist, bloom and light shafts finish the image. Quality adapts to the device (`?quality=low|medium|high` forces a tier).

| Key | Does |
|---|---|
| WASD / arrows | Walk (on AZERTY, ZQSD) |
| M | Sound on/off (sound starts on your first key or click) |
| E / Space / Enter, or click | Advance dialogue |
| `` ` `` (² on AZERTY) | Debug overlay: fps, location, quality tier, rendering toggles (shadows, reflections, bloom, depth of field, fog, grade), scene buttons |

Add `?debug` to the URL to open the overlay at start.

## Develop

```sh
npm install
npm run dev      # http://localhost:5173/rpg-claude/
npm test         # unit tests (Vitest)
npm run build    # typecheck and build into dist/
```

With the dev server running, `/rpg-claude/dev/preview.html?what=characters&scale=6` (or `what=faces`) shows the generated sprites enlarged.

## Layout

```
src/
  engine/   view geometry, input, RNG and noise, saves
    diorama/  the renderer: tilted orthographic camera, lights, shadows, reflections,
              depth of field, fog, bloom, grade; quality tiers and adaptive resolution
  pixel/    procedural pixel art: the PixelImage toolkit (ramps, dithering, outlines),
            characters, portraits, terrain, building parts, nature, props
  world3d/  the diorama's contents: terrain with heights, buildings as volumes,
            billboards, actors, water, sky, light shafts, ground clutter, particles
  world/    the director (camera moves for cinematics), the walkable grid and A*
  ui/       dialogue windows, location cards, letterbox bars
  audio/    Web Audio engine, synthesised instruments, generative chant, sound effects
  story/    flags, conditions and the script runner
  scenes/   screens of the game (for now, the Sea Gate)
  debug/    the debug overlay
tests/      unit tests
```

## Deployment

`.github/workflows/deploy.yml` builds and deploys to GitHub Pages on every push to `main`. One-time setup: in the repository's **Settings → Pages**, set **Source** to **GitHub Actions**.
