# Palimpsest

A story-driven, turn-based RPG for the browser (desktop and mobile), in HD-2D: pixel art standing in a lit 3D diorama, in the manner of Octopath Traveler.

In the realm of Hollin every soul is written in the Book of Names, and for ten years no one has died. Isot, a young scribe sentenced to be scraped out of the Book, escapes with an anchoress who has not left her cell in a decade and a knight who has forgotten his own name. Five chapters, a prologue and an epilogue: about 45 to 60 minutes, in English or French.

Built with Three.js, Vite and TypeScript. Every image, letter and sound is generated by code at runtime. The repository contains no asset files.

- **Design:** [DESIGN.md](DESIGN.md)
- **Play:** https://frault75.github.io/rpg-claude/ (deployed from `main` by GitHub Actions)

## Playing

Every enemy shows what it will do next, every fight is placed by hand and works as a small puzzle, and the party is fully restored after each one. There is no experience, no random encounter and no grinding. New abilities come with the story, and the eight items found along the way each bend one rule rather than raise a number.

Hold the candle (R) to tilt its light across a surface: scraped writing, painted-over doors and lost names show in the raking light.

| Key | Does |
|---|---|
| WASD / arrows | Walk (ZQSD on AZERTY); move in menus |
| Click or tap the ground | Walk there |
| E / Space / Enter | Talk, examine, confirm, advance dialogue |
| Backspace / X | Back, cancel |
| R (held) | Raking light: the candle |
| Esc / Tab | Pause: party and formation, equipment, journal, settings, save |
| J | The journal: what to do next, and the Lost Names found |
| 1–5 | In battle, pick a command directly |
| M | Sound on/off |
| Touch | A virtual stick under the left thumb; A, B, the candle and the menu on the right |
| Gamepad | Left stick or d-pad, A confirm, B back, Y candle, Start pause, Select journal |

Every binding can be changed in Settings, which also hold the language (detected from the browser), text size, sound levels and quality. The game saves itself at every checkpoint and can be saved by hand from the pause menu; Continue on the title picks up the latest save.

## Install and play offline

The build is a Progressive Web App: on a phone or desktop, "Add to Home Screen" / "Install" from the browser puts Palimpsest on the device, full screen and in landscape. A service worker precaches every file, so it then plays offline. The icons are drawn by code at build time (`build/pwa.ts`).

## Develop

```sh
npm install
npm run dev      # http://localhost:5173/rpg-claude/
npm test         # unit tests (Vitest)
npm run build    # typecheck and build into dist/
```

`` ` `` (² on AZERTY) opens the debug overlay: fps, location, quality tier, rendering toggles and story jumps. URL parameters start anywhere:

| Parameter | Starts |
|---|---|
| `?map=village&chapter=2` | On a map, with the party, abilities and items of that chapter (`&spawn=` picks the entrance) |
| `?scene=battle&fight=b3` | A fight (`f1`–`f9`, `b1`–`b5`) |
| `?scene=interlude&n=2` | An interlude page (`n=5` is the epilogue) |
| `?scene=prologue`, `?scene=seagate` | The opening cinematic, or the Sea Gate |
| `?quality=low\|medium\|high` | Forces a quality tier |
| `?debug` | Opens the overlay at start |

With the dev server running, `/rpg-claude/dev/preview.html?what=characters&scale=6` (or `what=faces`) shows the generated sprites enlarged.

## Layout

```
src/
  engine/   scenes, input and touch, settings, saves, RNG and noise, view geometry
    diorama/  the renderer: tilted orthographic camera, lights, shadows, reflections,
              depth of field, fog, bloom, grade; quality tiers and adaptive resolution
  pixel/    procedural pixel art: the PixelImage toolkit, characters, portraits,
            enemies, terrain, building parts, nature, props
  world3d/  the diorama's contents: terrain, buildings, billboards, actors, water, sky,
            light shafts, particles, and the sets of each region
  world/    the director (camera moves for cinematics), the walkable grid and A*
  maps/     every location: its layout and its scripts, by region
  battle/   the deterministic battle engine, the encounters, the battle HUD
  scenes/   title, prologue, maps, the Sea Gate, battles and their phase changes, interludes
  story/    game state, conditions, the script runner, journal, interludes, Lost Names
  data/     equipment and speakers
  menu/     the title and pause menus and their pages
  ui/       dialogue, location cards, illuminated pages, letterbox bars
  audio/    Web Audio engine, synthesised instruments, generative chant, each region's score
  i18n/     English and French
  debug/    the debug overlay
build/      the PWA plugin (procedural icons, manifest, service worker)
tests/      unit tests, including a solver that plays every fight
```

## Deployment

`.github/workflows/deploy.yml` builds and deploys to GitHub Pages on every push to `main`. One-time setup: in the repository's **Settings → Pages**, set **Source** to **GitHub Actions**.
