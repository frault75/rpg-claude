# Palimpsest

A story-driven, turn-based RPG for desktop browsers, drawn in the style of a medieval illuminated manuscript.

Built with Three.js, Vite and TypeScript. Every image, letter and sound is generated by code at runtime. The repository contains no asset files.

- **Design:** [DESIGN.md](DESIGN.md)
- **Play:** https://frault75.github.io/rpg-claude/ (deployed from `main` by GitHub Actions)

## Current milestone: (a) rendering pipeline and art style

A single test leaf: Isot walks a meadow below the Abbey of Saint Ebb's, framed by a bar-and-spray border.

| Key | Does |
|---|---|
| WASD / arrows | Walk (on AZERTY, ZQSD) |
| E / Space / Enter | Isot speaks (a banderole) |
| 1–5 | Repaint the leaf in each location's palette |
| F | Fray Isot (the illuminator's process run backwards) |
| M | Sound on/off (sound starts on your first key or click) |
| `` ` `` (² on AZERTY) | Debug overlay: fps, location, draw calls, post-processing toggles, scene buttons |

Add `?debug` to the URL to open the overlay at start.

## Develop

```sh
npm install
npm run dev      # http://localhost:5173/rpg-claude/
npm test         # unit tests (Vitest)
npm run build    # typecheck and build into dist/
```

## Layout

```
src/
  engine/   page geometry, renderer and layers, input, RNG and noise, post-processing (GLSL)
  art/      the Illuminator drawing API, pen, palettes, and the generators
            (architecture, figures, drolleries, nature, ornament)
  audio/    Web Audio engine, synthesised instruments, generative chant, sound effects
  scenes/   screens of the game (for now, the test leaf)
  debug/    the debug overlay
tests/      unit tests
```

## Deployment

`.github/workflows/deploy.yml` builds and deploys to GitHub Pages on every push to `main`. One-time setup: in the repository's **Settings → Pages**, set **Source** to **GitHub Actions**.
